<p>
  This project demonstrates how to build a Dockerized ETL pipeline using Python and dbt, with Docker serving as the foundational infrastructure..

<h2>How to Run</h2>
To start this pipeline, you just need to run the start.sh and it will automatically run the different containers from the docker-compose file. Also you can schedule to run via CRON.
